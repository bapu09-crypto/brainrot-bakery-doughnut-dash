A Steal-a-Brainrot-style Roblox game set in a bakery. Buy living pastry
characters off a conveyor belt, place them on pedestals at your own stall,
and earn money every second. Steal brainrots from other players' stalls,
defend yours with a lock and a Rolling Pin slap, and climb quests, goals,
upgrades and rebirths — with Burn Wave and Golden Hour events on the clock.

This is the simple rewrite: the same game, rebuilt fresh in five small,
data-driven Luau files.

Play it here: https://www.roblox.com/games/107058875463133/Brainrot-Bakery-Doughnut-Dash
